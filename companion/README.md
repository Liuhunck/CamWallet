# 电脑端 Python 工具

先做简单的 Python 命令行工具，按功能需要打开二维码显示或摄像头窗口。

## 职责

- 导入板端导出的公开地址。
- 通过 EVM RPC 查询余额、nonce 和费用参数，准备未签名交易。
- 显示待签名交易二维码，供板端摄像头扫描。
- 使用电脑摄像头读取板端显示的签名二维码。
- 验证签名与发送地址，组装已签名交易，由用户执行广播。

电脑端不接收、保存或使用真实钱包的助记词和私钥。与板端之间的数据交换使用二维码；电脑通过网络连接 RPC。

第一版对接板端的单账户 EIP-1559 Type 2 原生币转账流程，使用本地 EVM 测试链和测试密钥验收。

当前仅建立目录和职责说明，尚未添加 Python 脚本或依赖。
